# Portfolio Website

This repository contains a **personal portfolio website** built using [Vite](https://vitejs.dev/) and [React](https://reactjs.org/). The project showcases skills, projects, certifications, testimonials and provides visitors with a modern, responsive browsing experience.

---

## 🚀 Features

- Responsive layout using **Tailwind CSS**
- Animated sections and scroll effects
- Full project details with modals
- Certification carousel and achievement tracking
- Contact form with validation
- Dark mode support (if implemented)
- SEO-friendly meta tags and performance optimizations

## 🧱 Tech Stack

- **React** for UI components
- **Vite** as the build tool
- **Tailwind CSS** for styling
- **JavaScript** (ES6+) for logic
- **React hooks** for custom logic (`useIntersectionObserver`, `useScrollDirection`)

## 📁 Project Structure

Key folders:

- `src/components` – reusable UI components
- `src/hooks` – custom React hooks
- `src/utils` – helper functions and constants
- `src/styles` – global and component-specific CSS
- `public` – static assets (manifest, robots, sitemap)

See full structure in the workspace root.

## 🛠️ Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (>=16) and npm installed.

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view in the browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## ✅ Deployment

The site can be deployed to any static hosting service such as Netlify, Vercel, GitHub Pages, or Azure Static Web Apps. Simply upload the contents of the `dist` folder generated by the build command.
